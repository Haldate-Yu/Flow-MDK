## 协议要点与修正过程

1. **早停与课程学习冲突**：val 用恒定 H=8 rollout 评估，而课程学习早期模型只会
   1–2 步 → val 虚高触发早停（v1/v2 跑到 7–19 epoch 就停）。修正 = 关闭早停跑满
   40 epochs + 评 `last.pt`（与 SWE-GNN 的 150 epochs 预算逻辑一致）。修正后零样本
   稳定性大幅改善（B2 zxh 水深 RMSE 16.2 → 0.38–2.19 m 量级）。
2. 归档：`scripts/archive_datasets.py` 全量快照至 `datasets/`（源码/原始数据/算例/
   过程/结果 + MANIFEST），LFS 模式已配置。

## 诚实的解读（当前为 CPU 预算 40 epochs、G=32 的首轮）

- **域内（A）标准 GNN 基线占优——与论文结论表面矛盾的三点解释**：
  1. **参考解体制不同（最根本）**：论文的合成数据由 Delft3D-FM 全 SWE 生成（含
     对流惯性、动态波、类激波湿锋），而本仓库 Part A 真值来自**隐式扩散波**参考
     解算器（无对流项、单调光滑传播）。GCN 的对称平滑恰是纯扩散体制的最优滤波
     （S2GC 谱分析结论），差值消息架构模拟的"通量差分/对流"在此体制下没有优势
     ——这实际**印证**了 plan 备忘"传播算子必须匹配体制"的论断，也预示 B 部分
     （Mascaret 全 SWE 真值）才是差值消息架构的主场。
  2. **预算差距**：论文 G=64、2 层×8 跳、150 epochs、V100 GPU、80 个 4096-node
     场景；本轮 G=32、2×2/3 层、40 epochs、CPU、30 个 100-node 场景。结构较强
     的模型明显欠训练（其域外退化含欠训练成分）。
  3. **A→B 泛化 gap 首次量化**：gcn 几乎无退化（2.56→2.19），flow_mdk 2.7×
     （9.16→24.45），swegnn 2.5×（15.17→37.39）。
