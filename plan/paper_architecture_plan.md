## 0. 定位判断：证据链能支撑什么故事

已收口证据 → 可主张内容（与 L16 后修正口径一致）：

| # | 可主张内容 | 证据（已收口） |
|---|---|---|
| C1 | **残差式深传播 harness 是 2D ×5 级优势的主载体；定向 MDK 是显著稳定增量**（×1.2–1.6、方差减半、KS 显著）；匹配深度下**定向 MDK < 无分支 < 对称扩散**，定向门控是唯一正增益扩散形态 | E4/E5（三种子钉死）、L16（深度匹配消融） |
| C2 | **1D 诚实排位**：合成域内 GCN/GAT 最优；MDK 系价值域 = 真实几何域（B1 双协议 0.8 档最稳）+ 2D 激波体制；1D 排序对 Δt 稳健 | E3、MS5/E1 关闭、L14 |
| C3 | **synthetic→real 迁移**：训练视野内零样本成立（2D 考卷 H=8 全体 2.0–3.5 m，flow_mdk 最优最稳）；全时程发散定界；B1→B2 真实域内成立 | L12、L2/L3→L4 复测 |
| C4 | **评测方法学**：单种子结论不可信的实证演示（E2/E3 推翻 L4 两条判决）；漂移现象刻画；选点治理协议（E6/E6.1：best ×2.7、ema 最小方差） | E2/E3/E6/E6.1、M4 互证 |
| C5 | **统一基准与可复现管线**：1D/2D 各 130 合成场景 + 真实母版家族 130（B1 v2）+ 5 真实考卷 + 耦合链；TELEMAC-MASCARET 真值管线（内核补丁、复算校验、QC 门控）；SWE-GNN 协议对齐 | M0–M4、L1/L7/L11 |

这五条合起来是一篇**「机制 + 诚实评测 + 基准」**论文，而非 SOTA 论文——
正因如此，主战场是 EM&S 这类收"模型+软件+基准+可复现性"的期刊；1D 域内
排位在 SOTA 叙事下是致命伤，在机制叙事下反而是方法学卖点。

## 1. 路线选择（三案）

| 方案 | 内容 | 适用 |
|---|---|---|
| **A（推荐）** | **SCI 一篇主打（EM&S）**；中文核心作第二篇**应用向拆分**（见 §3） | 考核同时认可 SCI/中文核心；时间允许两篇 |
| B | 只投一篇中文核心 | 毕业要求仅为中文核心、需快速出文 |
| C | 同一数据、同一主张双语两投 | **不可取**——构成重复发表，勿选 |

**拆分纪律**（方案 A 必须遵守）：两篇的主张、实验侧重、正文文字三者完全
不同；SCI 主打机制+基准+方法学（全实验版图），中文核心主打真实流域应用
闭环（B1→B2→耦合→工程时效），互相引用、零文字复用。

### 2.5 审稿风险与预案

| 风险 | 预案 |
|---|---|
| "1D 域内 GCN/GAT 更优"被当成缺陷 | 正文明确其为**体制匹配结果**（对称平滑↔扩散波体制）；用 L14 证排序对 Δt 稳健；价值域重划（B1 真实域 0.8 档最稳 + 2D ×5）写成贡献而非辩护；E3 证该排位是三种子结论而非偶然 |
| "×5 到底是谁的功劳"被追问 | L16 已把归因拆干净，主动写（harness ×5.3–6.1 + MDK ×1.2–1.6/方差减半），摘要即如实分账——这是诚实卖点不是软肋 |
| 漂移根因未明 | 按现象+治理写，不强行解释；列开放问题；M4 单场景过拟合设定下漂移照样发生（×5.5）作为"训练动力学而非泛化现象"的旁证 |
| U-Net round 3 若很强 | U-Net 限规则网格，覆盖不了河网/耦合异构图——统一性主张不动摇；精度若相当则纳入 Pareto 讨论并如实报告 |
| M4 v2 家族不成 | 耦合章降级为 case study/可行性（已有"量级可用但粗糙"判读兜底），F7 换单链诊断图 |
| 加速比数字被质疑 | 坚持同环境口径（L9 服务器复算计时），分母分子同镜像；纸面先给本机口径并标注 |

### 3.2 叙事差异（与 SCI 版的切分）

- **视角**：面向真实流域洪水快速模拟的图神经网络代理模型——从合成训练到
  真实工程（应用闭环：真实母版家族训练 → 历史洪水考卷 → 耦合链 → 工程时效）。
- **方法压缩为一节**（定向传播+算子分裂简述，公式只留核心），消融仅一张表；
  方法学经验压缩为讨论小节（工程选型建议：多种子 + best/EMA 选点）。
- **强化工程要素**：闸门调度案例（mdx）、淹没 CSI 对应急管理的意义、加速比
  对预案滚动计算的时效价值。
- 不复用 SCI 文字；SCI 接收后投出（或明确拆分后并行），互相引用。
