## 0. 定位与对标基线（原文核实）

SWE-GNN（Bentivoglio et al., HESS 2023）的实际证据范围（第 4 节 + 局限节）：

| 项 | SWE-GNN 原文 | 本文（收窄后） |
|---|---|---|
| 算例 | 130 次二维溃口模拟，域 **6.4×6.4 / 12.8×12.8 km²**，网格 **64 / 128** | 二维合成 **130** 次，域 **64×64 @ 100 m = 6.4×6.4 km**（同尺寸同网格）+ 耦合 12 |
| 深度基线 | U-Net（CNN）一个 | GCN / GAT / U-Net / SSGC / -MDK 消融臂 |
| 真实算例 | **无**（局限节自述"需扩展到时变边界才更贴近真实情景"） | 真实漫滩考卷 ×2（零样本）+ 磨刀溪真实一二维链 |
| 一二维耦合 | 无 | 12 场景家族，65 189 节点单图 |
| 机理归因 | 无（骨架固定 2 层×8 跳） | 深度匹配三分消融，全部显著 |
| 加速比口径 | 未强调同环境 | 同节点同 docker 权威计时 |
| 种子/选点 | 单次训练 | 三种子 × last/best/ema 三协议 |

**结论**：收窄后只在"算例维度多样性"上少于原版图，其余每项均不低于对标文献。
本文的差异点是**机理归因 + 耦合能力 + 严格评测**，不是 SOTA 精度。

## 3. 主张清单（claim → evidence，全部为已验证数字）

| # | 主张 | 证据（数值均三种子；KS 为逐场景误差跨种子池化） |
|---|---|---|
| **C1** | **残差式深传播 harness 是二维 ×5 级优势的主载体；定向 MDK 是显著稳定增量** | 二维域内 last：flow_mdk **0.529±0.277** vs swegnn 5.060±6.600（**×9.6**）、U-Net 4.654±2.179（×8.8）、SSGC 1.820±1.573、GCN 0.871±0.206、GAT 0.716±0.001。KS 全显著：vs gat p=1.0e-06、vs gcn p=5.6e-11、vs ssgc p=1.3e-11、vs swegnn p=1.1e-08。**L16 深度匹配归因**：harness 独自 ×5.3–6.1，MDK 再 ×1.2–1.6 并压方差半（0.64→0.28）；三分排序**定向 < 无分支 < 对称**全显著。**新增 vanilla 深基线独立印证**：对 6 层 GCN/GAT 只领先 ×1.35–1.65（≈ MDK 那一份） |
| **C2** | **合成→真实二维迁移在训练视野内成立，全时程边界为 harness 级** | 真实漫滩（wqh_2d/mdx_2d，零样本，两考卷根逐字节同源、仅展开长度不同）：H=8 best flow_mdk **2.471±0.101** 最优（swegnn 2.643、ssgc 2.693、gcn 3.627、gat 3.635）。全时程（**S3 轨迹证据定案**）：MDK 系**真发散**——单调放大到真值峰值 4.6–9.5 倍（flow_mdk 18.335±7.881、ssgc 17.930±4.707、swegnn 17.930±11.972；探针峰值比 9.48/8.08/6.57）；vanilla gcn/gat 数值有界（2.086±0.020 / 2.075±0.004）但**峰值仅真值 0.507/0.508 倍、输出近乎恒定，未复现涨-落过程**——低 RMSE 系"真值大部分时间平稳 + 平均指标"的假象。**结论：视野外两边都不可用**（一边不稳定、一边无动力学），运营边界（视野内预演 + 周期校正）不变。**归因闭合**：补测 -MDK 臂（关掉扩散分支）同样发散（全时程 wqh 17.40 / mdx 8.11，峰值比 4.57）→ 发散属算子分裂 harness，与扩散分支无关、与残差增量解码无关；**并附带一条 C4 发现：长时程平均 RMSE 会奖励冻结预测** |
| **C3** | **异构单图的一二维耦合家族可训可评，且强工况下优势放大** | 65 189 节点（1D 34+29 断面 × 2D 65 126 单元 + 48 接口边），12 场景（9/1/2）。best **1.202±0.154** / ema **1.157±0.110** vs swegnn 1.491±0.082 / 1.574±0.018（**×1.24 / ×1.36**）；补 SSGC 对照 1.426±0.250 / 1.435±0.240 ≈ swegnn，**定向 vs 对称空白闭合**。最强工况 fam011（入流 ×1.97）：浅层三种子全恶化至 1.90 m 档，本文 1.34–1.63。守恒罚项负消融如实报告。**限制：测试集仅 2 场景，KS 无法执行、无显著性**（见补充实验 S1） |
| **C4** | **评测与选点方法学：单种子结论不可信、选点治理可救回 ×2.7 且跨架构有效** | E6 配方 best 4.811→**1.751**（×2.7，KS p=2.4e-11）；ema 为方差最小第三协议；跨架构：U-Net best 10.512→**0.915±0.236**，但其 last/ema 反恶化（4.654→13.903 / 12.853）→ 需按架构调 patience。单种子伪影实证：GCN last 塌缩 35.4 m 实为漂移伪影（best 0.777±0.032）。全部结论基于三种子 + KS |
| **C5** | **可复现基准：二维 130（与 SWE-GNN 同域同网格）+ 真实漫滩 2 + 耦合 12** | 真值管线 TELEMAC-MASCARET（内核补丁 `v8p4r0p1`、两段式初始化、复算逐位校验、质量守恒门控 ≤1e-15）；registry **901 run**；同环境 docker 计时；代码/数据可获取 |

## 6. 审稿风险与预案（收窄版）

| 风险 | 预案 |
|---|---|
| "为什么不做一维？" | 范围节一句话：亦在一维真实河网上评测并留档，该域普通基线更优（体制匹配），故不作价值主张；对标文献 SWE-GNN 亦为纯二维口径。**不隐藏、不主张** |
| "×9.6 是跟谁比？" | 明写对谁 ×几：对浅层 SWE-GNN 骨架 ×9.6、对 U-Net ×8.8、对 6 层 vanilla GNN ×1.35–1.65。后者与 L16 的 MDK 增量定量吻合——主动分账是诚实卖点 |
| "耦合结论有统计支撑吗？" | **当前没有**（测试集仅 2 场景）→ 必须做 S1 扩样；在扩样前，耦合章只能写作 case study，不得宣称统计显著 |
| "全时程为什么你的方法发散而基线不发散？" | 归因已闭合到 harness 级（-MDK 臂同样发散），F10 轨迹证据（S3 已完成）显示：MDK 系真发散（峰值 4.6–9.5× 真值），vanilla 基线不发散但**峰值仅 0.5× 真值、近乎恒定**——**两边都不可用于视野外**，同时把"平均 RMSE 奖励冻结预测"写成 C4 的指标批判（这比原叙述更有力） |
| "真实算例只有 2 个漫滩" | 对标文献零真实算例；本文另有磨刀溪真实耦合链作工程应用章；如实写明考卷数量与切分 |
| 漂移根因未明 | 按现象 + 治理写，列开放问题；M4 单场景过拟合设定下漂移照样发生（×5.5）作旁证 |
